Detailed Description

Implements the brute-force algorithm for the 0/1 knapsack problem.

Contains the main bruteForce function and its recursive helper (backtrack). This algorithm explores all possible combinations of pallets to find the most profitable subset that fits within the truck's weight capacity.

void bruteForce ( const Truck & truck,
const std::vector< Pallet > & pallets )

Solves the 0/1 knapsack problem using brute-force approach.

This function tries every possible combination of pallets to find the subset with the maximum profit that fits within the truck's weight capacity.

Parameters
truckThe truck object containing the capacity and number of pallets.
palletsA vector of Pallet objects available to choose from.
Note
Time complexity: O(2^n), where n is the number of pallets.
Space complexity: O(n), where n is the number of pallets (due to the subset vectors).
