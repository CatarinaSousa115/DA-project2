Hybrid algorithm combining greedy and dynamic programming approaches.

Executes a greedy algorithm to get an initial solution and profit, then runs a dynamic programming algorithm with pruning to find an optimal or improved solution. Compares the final result with the greedy one.

Parameters
truckThe truck object with a defined capacity.
palletsThe list of available pallets with weight and profit.
Note
Time complexity: Depends on pruning efficiency. Worst-case: O(n * W), where n is the number of pallets and W is the truck capacity. Best-case: close to O(n log n), leveraging greedy shortcut.
Space complexity: O(n * W), due to the DP table and auxiliary structures.
