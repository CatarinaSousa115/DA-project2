Allows the user to choose which algorithm to apply for pallet packing optimization. 

Presents a list of available algorithms and calls the corresponding function based on user selection.


\begin{DoxyParams}{Parameters}
{\em truck} & The truck configuration including capacity and number of pallets. \\
\hline
{\em pallets} & The list of available pallets to consider. \\
\hline
\end{DoxyParams}
\begin{DoxyNote}{Note}
Brute-\/force method\+: tests all possible combinations (may be slow).

Dynamic programming\+: uses DP table to find optimal solution efficiently.

Greedy algorithm\+: selects pallets based on profit-\/to-\/weight ratio.

Hybrid algorithm\+: combines greedy and DP for improved performance.

Exit\+: terminates the program.
\end{DoxyNote}
