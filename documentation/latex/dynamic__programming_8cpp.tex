\doxysubsection{Detailed Description}
Implements the dynamic programming algorithm for the 0/1 knapsack problem. 

This file contains the function that calculates the most profitable combination of pallets that fit within the truck\textquotesingle{}s weight capacity using dynamic programming.

Solves the 0/1 knapsack problem using dynamic programming. 

Fills a 2D table where each cell represents the maximum profit achievable using the first i pallets with a given capacity w. Reconstructs the optimal set of pallets based on this table.
