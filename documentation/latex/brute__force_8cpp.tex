\doxysubsection{Detailed Description}
Implements the brute-\/force algorithm for the 0/1 knapsack problem. 

Contains the main brute\+Force function and its recursive helper (backtrack). This algorithm explores all possible combinations of pallets to find the most profitable subset that fits within the truck\textquotesingle{}s weight capacity.
